## Open-source engineering

**[Peregrine — VTOL FPV tail-sitter](https://github.com/Bennyco86/peregrine-vtol)**  
A hobby aircraft design combining parametric CAD, a 3D-printable airframe, electronics packaging, wiring, CFD and ArduPilot configuration. The public repository includes STEP CAD, a bill of materials, wiring instructions and setup documentation. **First build and hover testing are pending; 200 km/h is a design target, not a measured flight result.**

**[Ultron Onshape MCP](https://github.com/Bennyco86/ultron-onshape-mcp)**  
My performance-focused fork of Reshef Elisha's jarvis-onshape-mcp, connecting AI assistants with parametric Onshape CAD workflows, model inspection and visual verification.

**[3D Printing Pulse](https://github.com/Bennyco86/3DprintingPulse)**  
An automated daily 3D-printing news digest for Quality3Ds.

**[Bambu Lab Chamber Heater Control](https://github.com/Bennyco86/BambuLabChamberHeater)**  
An n8n, MQTT and Python workflow for printer auto-resume and chamber-heater control, with an always-on Orange Pi bridge and cached temperature data.

Some app repositories contain public product, privacy and support pages; the app table above links to product information and official downloads.
